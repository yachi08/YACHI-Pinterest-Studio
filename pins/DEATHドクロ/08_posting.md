# 投稿用まとめ（承認済み 2026-10-24）

[ピン作成ツール](https://jp.pinterest.com/pin-creation-tool/)で、1本ずつ次の順に入れる。

1. 画像をアップロード
2. タイトルを貼る
3. 説明文を貼る
4. リンクを貼る
   - 「商品をタグ付けする」では、このステッカーの商品ページだけをタグ付けする
5. ボード「NECLEFX ステッカー」を選ぶ（最初の1本で新しく作る）
6. 「AI修正画像というラベルを表示する」にチェックを入れる
7. 公開する

投稿したら「DEATHピン1：（URL）」のように番号付きでURLを社長へ送る。社長の提案：1日1〜2本ずつ、ピン1から順に出す。聖母マリア青の残り（ピン3〜5）と交互に出してもよい。
