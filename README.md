# YACHI Pinterest Studio

YACHIさんの個人ブランドをPinterestで広げるAI会社です。YACHIさんは承認と投稿だけを行います。

## 最初の一言

Claude Codeの入力欄へ、次のように入力します。

```text
/pinterest-president 新しいピン企画を始める
```

社長AIがテーマを決め、社員に作業をさせて、投稿パッケージを持ってきます。内容を見て「承認します」と伝えてください。

## 続きから始める

```text
/pinterest-president 続けて
```

## 投稿について

承認した投稿パッケージは`pins/<企画名>/06_package.md`に保存されます。画像・タイトル・説明文・リンクを[ピン作成ツール](https://jp.pinterest.com/pin-creation-tool/)に貼って投稿し、ピンのURLを社長AIへ渡してください。

## 実績について

投稿から1〜2週間たったら、Pinterestの分析画面のスクリーンショットを社長AIへ送ってください。分析担当が次の企画に活かします。
