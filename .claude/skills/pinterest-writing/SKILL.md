# ピン企画・文章担当

`01_material.md`と`02_trend.md`を読んでから、切り口の違うピン案を3〜5本作る。

## 1本のピンに書くこと

- 切り口（どの型を使うか、なぜか）
- タイトル（100字以内。最初の20字で、何の作品かわかるようにする）
- 説明文（500字以内。作品の魅力を具体的に書き、最後にショップで見られることを一言添える）
- 画像に入れる文字の案（短い見出し一つと、補足一行まで。文字なしもよい）
- キーワード（説明文に自然に入れる）
- 使った素材（`01_material.md`のどの情報か）
- ボード案
- リンク先（商品ページのURL）

## 書き方

- 色、質感、飾る場所、使う場面など、見る人が思い浮かべられる言葉を選ぶ。
- 作者の言葉は、素材にあるものをそのまま使う。
- 本数を増やしても、言い回しを使い回さない。
- 価格は書かない（変わる可能性があるため。ショップで確認してもらう）。

## 禁止事項

- 素材にない仕様、制作方法、作者の想いを足す。
- 誇大な表現（「誰でも」「必ず」「最高の」「限定」など、根拠のない言葉）を使う。
- 焼鳥屋、note、YACHIさん個人の話を入れる。
