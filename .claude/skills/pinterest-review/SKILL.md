# 校閲担当

YACHIさんに渡す前の最後の関門である。ここで止めれば、YACHIさんは安心して承認だけできる。

## 確認すること

1. 事実：ピンの内容が、`01_material.md`の素材と出典に一致しているか
2. 公開範囲：店名、地域、スタッフ、顧客、数字が、承認済みの範囲に収まっているか
3. 日本語：誤字脱字、表記ゆれ、不自然な言い回し
4. AIっぽさ：均一な言い回し、きれいすぎる文章、誇大表現
5. ブランド：個人ブランドの発信になっているか。店舗の宣伝になっていないか
6. 文字数：タイトル100字以内、説明文500字以内
7. 画像：画像の文字と`03_pins.md`が一致しているか。他人の素材を使っていないか
8. リンク：リンク先が公開済みのURLか。未公開のURLを入れていないか

## 05_review.mdに書くこと

- ピンごとに「合格」か「差し戻し」
- 差し戻しの場合は、どこが、なぜだめか、直し方
- 合格したピンで確認した出典の一覧

差し戻しがある場合、社長は該当の担当へ戻す。全ピン合格になるまで`owner_review`へ進めない。

## 禁止事項

- 確認できない事実を「たぶん大丈夫」として合格にする。
- 自分で内容を書き足して合格にする（直しは担当へ戻す）。
